# Use Cases

The application is descried in use cases. The details of the use cases shall
be described in files grouped in subfolders per category.

## User

* UC-US-001 - user registration
* UC-US-002 - password reset
* UC-US-003 - login
* UC-US-004 - send squad invitation

## Squad

* UC-GR-001 - create new squad
* UC-GR-002 - manage trainers
* UC-GR-003 - manage players
* UC-GR-004 - manage guardians
* UC-GR-005 - edit guardian
* UC-GR-006 - manage shirt sets
* UC-GR-008 - enable or disable match planning
* UC-GR-009 - manage match formats
* UC-GR-010 - manage formations
* UC-GR-011 - link or unlink a Spond group
* UC-GR-012 - synchronize players and guardians from Spond
* UC-GR-014 - manage squad periods
* UC-GR-015 - deactivate a squad

## Event

* UC-EV-001 - create event
* UC-EV-002 - manually add player RSVP data
* UC-EV-003 - select players for teams
* UC-EV-004 - manually change player RSVP status
* UC-EV-005 - assign shirt set
* UC-EV-006 - assign match format to event
* UC-EV-007 - select team formation
* UC-EV-008 - plan per-period lineup
* UC-EV-009 - assign team trainer
* UC-EV-010 - record attendance after an activity
* UC-EV-012 - synchronize events from Spond

## Statistics

* UC-ST-001 - Player Statistics
* UC-ST-002 - Event Participation Overview
* UC-ST-003 - Team Selections
